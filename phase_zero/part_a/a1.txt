Before Phase 1, we need to make sure your C++ fundamentals are strong enough that programming syntax never becomes an obstacle when solving DSA problems.

I'm going to treat you as someone who wants to become exceptionally good, not someone who just wants to pass basic coding questions.

Our objective for Phase 0:

By the end, you should be able to:
- Write C++ programs independently.
- Understand how memory, pointers, references and functions work.
- Work comfortably with arrays, strings and recursion.
- Use the C++ STL without constantly looking up syntax.
- Read unfamiliar code and debug it.
- Solve basic implementation problems without tutorials.
One important distinction: Phase 0 is primarily about programming fluency. We won't artificially force every exercise onto LeetCode. We'll use Codeforces and Striver for implementation practice and independent exercises for language fundamentals.
