C2. Bitwise operators
Master each operator independently:
Operator	Meaning	Example
&	AND	5 & 3 = 1
\|	OR	5 \| 3 = 7
^	XOR	5 ^ 3 = 6
~	NOT	Inverts bits
<<	Left shift	5 << 1 = 10
>>	Right shift	5 >> 1 = 2

Practice exercises:
- [ ] Check whether a number is odd or even using bits.
- [ ] Check whether the ith bit is set.
- [ ] Set the ith bit.
- [ ] Clear the ith bit.
- [ ] Toggle the ith bit.
- [ ] Extract the ith bit.
- [ ] Count set bits.
- [ ] Find the rightmost set bit.
- [ ] Remove the rightmost set bit.
- [ ] Check whether a number is a power of two.
- [ ] Swap two numbers using XOR.
- [ ] Find the XOR of a range.
