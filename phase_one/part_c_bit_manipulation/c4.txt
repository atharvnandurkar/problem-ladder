C4. Bit masking and subset generation
This is the bridge between ordinary bit manipulation and advanced DP.

Concepts:
- Bit masks.
- Representing sets using integers.
- Enumerating all subsets.
- Checking membership.
- Adding and removing elements from a mask.
- Enumerating submasks.
- Bitmask complexity.
- Bitmask DP introduction.
For an array of size \(n\), the number of subsets is:
2^n

You must understand how each integer from 0 to \(2^n-1\) represents a subset.
